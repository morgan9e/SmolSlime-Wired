# SlimeVR nRF: stock firmware with small changes

Stock SlimeVR nRF receiver and tracker firmware, with only the changes this setup uses
(nRF52840 Dongle receiver, ProMicro stacked SPI trackers).

| Path | What |
|------|------|
| `Receiver` | SlimeVR-Tracker-nRF-Receiver (git subtree of upstream) |
| `Tracker` | SlimeVR-Tracker-nRF (git subtree of upstream) |
| `tools` | PC tools |
